# app-updates

開発中のアプリの更新を配る場所です（公開）。**秘密の情報（鍵・API キー・会議の中身）は置きません。**

## きまり

- アプリごとにフォルダを1つ作る（例: `audio-minutes-ai/`）。
- フォルダの中:
  - `versions.json` … 版の一覧（版数・試験版 beta／正式版 stable・日付・更新内容・取得先・sha512・署名）。形は全アプリ共通（format 1）。
  - `v/<版数>/latest.yml` … その版を取るための案内（electron-updater 用。取得先は配布ページの絶対 URL）。
  - `public-key.pem` … 署名を確かめる鍵（アプリにも同じものが入っている）。
- インストーラー本体は配布ページ（Releases）に置く。版の名前は「<アプリ名>-v<版数>」（例: `audio-minutes-ai-v1.49.0`）。
  リポジトリの中に直接置かない（GitHub は1ファイル 100MB まで）。
- 署名の鍵はアプリごとに別にする（1つが漏れても、ほかのアプリに偽物を入れられないように）。
- 書き込むのは各アプリのリポジトリの自動の仕組み（GitHub Actions）だけ。手で直さない。
- 新しい版はまず「試験版」で置き、実機で確かめてから「正式版」に上げる。
